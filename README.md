# 演示机盘点与系统还原平台

手机门店演示机全生命周期管理：门店 / 展台 / 设备登记，每日开闭店盘点，
顾客试用异常处理，系统还原与版本校验，调店交接与退仓复核。
纯 Python 标准库实现（无第三方依赖），设备与演示账号均为样例。

## 一条命令启动

```bash
python3 run.py            # 默认 http://127.0.0.1:8000
PORT=8080 python3 run.py  # 指定端口
python3 run.py --reseed   # 清空并重新生成样例
```

首次启动自动完成：建库（SQLite）→ 写入门店/展台/设备/演示账号样例 →
生成**离线设备、展位错放、调店在途、待还原、刷机失败重试**样例 →
启动进程内任务（盘点提醒 + 还原失败自动重试，每 20 秒一轮）。

## 运行测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：序列号唯一（重复拒绝 / 同一序列号不能同时属于两个展位）、
盘点并发版本冲突、还原前置与权限、调店批准权限与展位冻结、
外观证据强制上传与留档不可删，以及 HTTP 端到端冒烟。

## 角色与权限

| 角色 | 权限 |
|---|---|
| 导购 | 只能上报异常 |
| 店长 | 登记/移位设备、执行并完成盘点、修改盘点结论、批准调店、退仓复核 |
| 技术员 | 执行盘点（不能改结论）、执行还原 |

页面右上角可切换身份（演示用），服务端按 `X-User-Id` 逐接口鉴权。

## 业务规则

- **开店盘点**：逐台确认位置 / 电量 / 外观 / 联网；发现设置变更或异常内容
  → 设备进入**待还原**并自动生成还原任务。
- **闭店盘点**：核对序列号与配件（充电底座、防盗线）；序列号未核对到 →
  **闭店少机**异常；配件缺失 → **防盗线报警**异常。
- **还原**：技术员刷入离线配置包后，演示账号、应用、壁纸逐字段校验，
  全部一致才回到**可展示**；失败自动生成异常并由进程内任务重试（≤3 次）。
- **调店**：店长批准后**冻结原展位**并生成交接记录（序列号、配件、账号快照）；
  目标店收货上架，或拒收 → 设备退回原店并生成**调店拒收**异常。
- **退仓**：复核三项（配件齐全 / 证据留存 / 账号已清）全部确认后设备退仓。
- **并发**：设备、盘点明细、调店单均带版本号乐观锁，冲突返回 409。
- **八类异常分别处理**：离线 / 防盗报警 / 划伤（须传证据）/ 账号登出 /
  还原失败 / 展位错放（须指定纠正展台）/ 闭店少机（须店长确认找回）/ 调店拒收。

## 目录结构

```
run.py               启动命令
app/
  db.py              SQLite 连接与建表
  adapters.py        模拟适配器：设备管理(MDM) + 防盗充电底座
  services.py        业务规则与权限（全部领域逻辑）
  server.py          HTTP 服务与 JSON API
  seed.py            样例数据（含离线/错位/调店样例）
  tasks.py           进程内任务：盘点提醒、失败重试
static/              前端（展台白 / 曜石黑 / 品牌蓝）
tests/test_platform.py
data/                运行时生成：app.db、evidence/ 外观证据、
                     packages/ 离线配置包、adapter_state.json
```

## 界面

- **展台平面图**：严格按柜面坐标排布，设备缩略图统一 3:4 比例，冻结展位斜纹标识。
- **盘点**：逐台聚焦卡片 + 固定底部操作条（进度圆点 / 上一台 / 保存并下一台 / 结束盘点）。
- **还原队列**：期望配置（离线包）与实际配置（设备）并排展示，差异字段整行高亮。
- **版本校验**：一键全量逐字段比对。
- **调店交接 / 退仓复核 / 异常登记 / 通知审计**：状态时间线与角色化操作按钮。
